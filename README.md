# NDF CONNECT

Démo front-end responsive conçue pour présenter l’application NDF CONNECT.

## Contenu de la démo

- profil de présentation : Xavier Ogandaga ;
- accueil et suivi du dossier ;
- gestion interactive des dépenses ;
- coffre-fort avec création de catégories personnalisées ;
- ajout et reclassement simulés de documents ;
- checklist, connexions et profil ;
- interface adaptée aux ordinateurs et aux téléphones.

Les données sont fictives et conservées uniquement en mémoire. Recharger la page réinitialise la démonstration. Aucune clé Supabase n’est nécessaire pour lancer le front.

## Télécharger et lancer

1. Télécharger le fichier `NDF_CONNECT-source.zip` depuis ce dépôt.
2. Extraire l’archive.
3. Ouvrir un terminal dans le dossier extrait.
4. Exécuter :

```bash
npm install
npm run dev:web
```

Ouvrir ensuite [http://localhost:3000](http://localhost:3000).

## Présentation conseillée

Ouvrir l’accueil, ajouter une dépense, consulter le coffre-fort, créer une catégorie, puis compléter une pièce dans la checklist.
